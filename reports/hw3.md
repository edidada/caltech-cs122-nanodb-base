# CS122 HW3：表统计与计划成本

采用 [官方 Winter2019 Assignment 3](https://courses.cms.caltech.edu/cs122/assignments/lab3.html)，从 HW2 最终提交 f3b9bb2 建立 `edidada/hw3`。本课新版未被另一门 CS121 替换。独立 `.github/workflows/hw3.yml` 使用 JDK17，Maven 与 Gradle 均保留；本机只编辑和静态检查，Java 编译、测试、完整数据实验均在 Actions 执行。

单遍直接扫描数据页，跳过 HW1 空闲目录和空槽，统计行数、物理 tuple 字节、数据页、非 NULL distinct、NULL 数及适合比例估算类型的 min/max；finally 释放引用，saveMetadata 写入文件头，关闭重开后验证。字符串只收 distinct/NULL，不存 min/max。空表平均长度为0。distinct 使用官方内存 HashSet，不声称外存可扩展。

选择率使用独立性假设：AND 连乘，OR=1-各补概率连乘，NOT取补；等值约1/V，列间等值约1/max(Va,Vb)。范围采用截断到[0,1]的均匀 min/max 比例，退化常量域单独处理，未知统计或不支持的谓词回退25%。常量真假与NULL比较单独处理。此为题目简化模型，不是完整SQL三值逻辑概率模型；特别是普通比较的非NULL比例未由行总数校正。

StatisticsUpdater 深拷贝输入，处理列与常量比较及递归AND；等值缩为单点，范围收紧边界并缩 distinct，!=估计扣一。严格范围保留包络端点近似，不虚构下一个实际值；OR/NOT不传播。比值通过BigDecimal避免long相减溢出，并支持日期/时间坐标。

FileScan CPU按输入行数、输出按选择率；Filter累加输入行数；NestedLoop按左右子成本和所有比较对累计，外连接至少保留外侧行估计。IO按题目“内存充足的最佳情况”读取两侧各一次，不能当成真实读取测量。位置绑定列同步传播统计，支持NATURAL/USING与RIGHT的物理交换；空排序避免0*log(0)的NaN。自动连接顺序优化是HW4，本次不混算。
